Growth

This app I made is called Production Pal which I essentially made to help aspiring musicians like myself navigate production tools so that they can make and record music on their own. I think this work represents growth for me because it was my first project and it shows how I went from absolutely zero knowledge to the ability to make an app. I used design tools I never used, code I had never heard of like setScreen or onEvent to make an app that actually functions. The hardest thing for me to master was probably the input sections of my code because honestly I had no idea how that worked or what it even meant. The hardest thing for me during this was getting all my buttons to work. On this app I had a lot of screens that I wanted to connect with one another and so it was hard to find a way to make all those little buttons work just because I had little knowledge of how the code even worked. I think I put a lot of effort into this project so it made it more cool to look at and use. It was my first project so I was really focused on making it the best I could and I think because of that it came out better than I had originally expected. Knowing what I know now, I would probably just make more pages and make it more interactive. The app is kind of like a demo and I don’t think anyone would actually use it to learn how to produce, but developing it into a better functioning, real app, may be fun.
